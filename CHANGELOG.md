## [0.1.0-beta] - 2026-05-21

### Added
- **Encrypted Vault**: Secure storage for SSH passwords and private keys using AES-256-GCM.
- **Interactive Web Terminal**: Real-time SSH access powered by xterm.js and Laravel Reverb.
- **Audit Trails**: Connection logging system with a dedicated UI to track IP addresses, durations, and statuses.
- **Server Management**: CRUD operations for servers with tagging and group organization.
- **Import/Export**: Support for importing from SSH config files, CSV, and JSON.
- **Mobile Responsive UI**: Fully adaptive interface with card-based layouts for mobile devices.
- **Docker Support**: High-performance deployment stack using FrankenPHP.
- **Deployment Manifests**: One-click deployment templates for Railway and Coolify.
- **Professional Landing Page**: Integrated welcome and comparison pages for public visibility.
- **Support Integration**: Integrated Ko-fi donation links and developer attribution.
